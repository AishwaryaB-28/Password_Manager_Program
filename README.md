# Password_Manager_Program

Build a password manager program that allows user to put up a website and enter the password you want to be saved. 

What will this project do?

1. Save password
2. View password
3. Generate password
4. Store password
5. Exit

Concepts used:

1. Dictionary
2. Loops
3. Conditional statements
4. Module: random
5. File handling [read/write] is used so the password for the website will remain safe.
